# 闭环证据图规划

核心问题：步骤 3 超范围候选能否以真实 A* 导航到成功站位，再无重置完成严格抓取？

- 选择实际导航轨迹与规划路线叠图：标出 P131、停靠点、A、目标、桌面边界；区分规划与实测，不把 A* 规划图当物理通过。
- 选择每次实测目标抬升曲线：时间以该次 Pick 开始为零，抬升阈值 .05 m；不把高度曲线单独当完整成功验收。
- 选择起点/导航/抬升/保持视频预览：来自保存的真实状态，检查画面遮挡、字幕和指标一致性。
- 不画成功概率/统计置信区间：仅三次冻结构造重复试验，不支持总体概率推断。

图属于证据，源模块、PNG/SVG、原始 JSON 路径和视频溯源保留。交付前实际查看 PNG 与视频抽帧；不声称浏览器截图验收。
