## 执行方式与 MoMa-Kitchen 对应

参考 [MoMa-Kitchen 数据生成流程解析](../../../../MoMaKitchen/MoMa-Kitchen_数据生成流程解析.md) 中“候选底盘 → 独立操作 oracle → 稀疏地面标签 → Gaussian 插值”的方式；没有复制其未公开的 collection loop，也没有把其低层控制器假定为 cuRobo。

1. **冻结输入与审批。** 校验原恢复包、协议、稳定性原轨迹及来源；配置/预期在运行前写入 frozen_inputs。中断后按同一审批、配置和场景哈希续跑。
2. **目标附近操作带采样。** 三个获准桌边，沿边约 0.30 m；边距 0.32 / 0.48 / 0.64 m；面向目标及 ±20°。保留精确 A 点，共 58 个 XY 位置、172 个 pose。
3. **先几何筛选。** 实际地面覆盖、完整机器人初始碰撞和独立解析接触上界分别判定；未删墙、未移目标、未搬家具。上界 **1.217 m**，覆盖双臂、任意 yaw、任意臂配置和连续合法躯干联动，不来自 IK 搜索失败。
4. **双臂五高度规划。** 对 72 个几何合格 pose，检查左右臂 × h=[0,0.1845,0.369,0.5535,0.738]，固定 grasp 794；64 IK seeds、4 trajopt seeds、最多 5 attempts。保留真实环境 collision mesh 与机器人其他部分；三个路径为预抓取、接近、抬升。只作筛选。
5. **关键点独立物理执行。** 先 A 控制，再路径通过点的空间覆盖和朝向/双臂补充，最后两次边界搜索诊断。每次恢复原全状态，只设置底盘位置；躯干重新动态调整，重新规划，执行闭合、抬升和保持。放置机器人不是导航成功。
6. **稀疏与局部插值。** 10 条完整 Pick 二值结果关联到最近真实地面网格点，全部匹配成功；2 条未完成 Pick 的搜索诊断不进入二值标签。同一 XY 的已测臂/朝向标签先求均值（不是重复随机试验成功率），再做 kNN=3、σ=0.12 m、最多 0.30 m 局部支持；远处为 NaN，不填 0。桌面 footprint / 环境 AABB 只作保守显示遮罩，不能当导航地图。

## 覆盖与实际结果

| 环节 | 数量 | 正确解释 |
|---|---:|---|
| 候选 pose（含 yaw） | 172 | 58 个不同 XY；非全屋采样 |
| 初始机器人碰撞过滤 | 74 | 几何拒绝，不是 Pick 失败标签 |
| 超出保守接触界 | 26 | 解析界外，与预算无解分开 |
| 进入规划的 pose | 72 | 每个都检查双臂与五个 h |
| 完整规划查询 | 720 | 无缺项、无重复 |
| 三段路径通过 | 41 组 / 13 pose | 不是物理成功 |
| 新物理试验 | 12 | 每次从同一源快照独立初始化 |
| 严格 Pick 通过 | 9 次 / 7 个 XY | 左臂 7 次、右臂 2 次；单次，不估计区域成功率 |
| 完整执行严格失败 | 1 | T08 的躯干约束超限 |
| 未完成 Pick | 2 | T10 / T11 预算内无解，不进入二值 GT |

**A 对照符合事先预期；其余点在执行前未知。** 这次关掉了“北侧/西侧只有规划可行但未真正抓取”的不确定性；剩余主要问题是区域稳定性和真实绕行，而非继续猜测 IK 是否等于成功。

T08 在 `[7.5544, 2.6081, -2.0127]`、右臂、h=.738 下，躯干最大联动误差 **0.002605 rad > 0.002 rad**，严格判失败，没有放宽阈值。同一 XY 另有配置通过，因此图用绿点加红圈，不能把该点当作“所有朝向/双臂不可达”。**T08 不是 Case 1-R 距离不可达证据**，后续不要据它构造纯距离失败起点。
