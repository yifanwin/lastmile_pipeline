# 步骤 3 配图与判定计划

- 问题：冻结目标与场景，哪些有限采样底盘位姿在稳定 grasp 794 协议下可真实抓取？
- 已有 baseline：A 点左臂 h=.738 历史名义 5/5、扰动 20/20，新实跑 1/1；不推广到区域。
- 事先预期：A 控制应通过；其他站位结果未知。失败不放宽约束。空间采样、规划预算与 12 次物理上限已在 frozen_inputs 中冻结。
- 主图：世界 xy 稀疏站位图，合并同 XY 的采样 yaw，物理优先；各证据层有独立图例、朝向箭头及底盘范围界。类别为证据，保留 PNG/SVG 和生成代码。
- 副图：只基于完整动态 Pick 标签的 kNN Gaussian 局部插值。未知地面保持空白，不作成功概率或物理标签。类别为解释，保留 NPZ 与主图中的预览。
- 明细表：逐 pose/arm/h 检查和全部实跑结果，支撑用户下一步选择。
- 不选择：全屋无支持密集热图、导航成功路线、成功率误差棒。理由：未测试区域/导航无证据，逐站位仅单次试验。
- 证据充分性：原始 Pick 轨迹重新严格验收；逐 trial 放置快照除 base 外 qpos 与所有 qvel 应与原始快照完全一致；多高度/双臂矩阵完整且无重复。
- A 控制失败时：保留地图，但标记对照未通过；不能借此声称新区域真实可行。
- 不确定性：冻结单 grasp 与离散 yaw/h、有限搜索预算、各点单次结果；不声称同侧全局不可达或稳定成功率。
